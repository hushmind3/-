학습 가능한 남은 경험—모델 저장 완료 기준

Champion과 Candidate의 고정 시험본을 같은 새 가상계좌 조건에서 비교합니다. 시험본이 보지 못한 미래 최소 390개 시장 분 구간에서 Candidate 시험본이 이익을 내고 Champion을 이겼을 때만 오전 7시에 승급합니다. 원래 두 모델은 그동안 계속 학습하며, 다음 시험은 최신 두 모델을 다시 고정한 이후 구간에서 시작합니다.

128칸은 한 번에 보는 입력 길이입니다. 하루 학습량 제한이 아닙니다. 남은 경험은 장 마감·주말·재시작 뒤에도 순서대로 학습하며, Champion과 Candidate 모두 학습과 저장을 완료한 항목만 삭제합니다.

학습 불가: —건 · 원인 확인 중. 양쪽 학습·저장 완료 후 아직 DB에 남은 정상 경험: —건.

경험 1건은 종목·판단 시점·보상 종류로 구분합니다. 하루 봉 수나 저장된 시세 행 수와 같은 단위가 아닙니다. DB가 작아진 것은 완료 경험을 지웠기 때문일 수 있으며, 아래 생성·완료 누계로 확인합니다. 과거 반복 학습 기록은 유지합니다.

현재 반복 횟수를 불러오는 중입니다. 같은 GPU에서 학습 회차를 번갈아 실행하고, 둘 다 가중치 저장이 끝난 경험만 지웁니다. 서로 다른 시각의 경험과 모든 시간봉 입력은 유지합니다.

학습 보상 · 매매 방식 · 체결 환경의 한계

공통 시장 입력은 두 모델 모두 필수로 관찰합니다. 각자의 행동과 비용 차감 손익을 같은 replay에 합쳐 두 모델이 각각 학습합니다. 운영 계좌에서는 같은 난수로 확률에 따라 행동을 추첨하고, 하루 승급전에서는 양쪽 고정본이 최고 확률 행동을 선택합니다.

입력은 1·3·5·15·60분봉과 일·주·월봉 요약입니다. 키움 체결 틱도 1분봉으로 집계합니다. 전체 호가 단계·주문 대기 순서·실제 체결 유동성은 재현하지 않으며, 이 환경은 1초 단타의 성과 검증이 아닙니다.
