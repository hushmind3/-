## TimesFM-20M (TSFM) — Global (2023)

This is the **Time Series Foundation Model (TSFM)**, pre-trained on **global financial time series data up to the year 2023** using the **TimesFM architecture (20M)**. The dataset spans from **1990–2023** and includes all **global excess return data**.
