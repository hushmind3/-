## Chronos-Small (TSFM) — Global (2023)

This is the **Time Series Foundation Model (TSFM)**, pre-trained on **global financial time series data up to the year 2023** using the **Chronos architecture (Small size)**. The dataset spans from **1990–2023** and includes all **global excess return data**.
